List interfaces:
python src/main.py --interfaces

Capture 20 live packets:
python src/main.py --live --count 20

Capture TCP packets:
python src/main.py --live --count 50 --protocol tcp

Read a pcap file:
python src/main.py --pcap examples/sample.pcap

Save summaries to CSV:
python src/main.py --live --count 100 --save packets.csv
